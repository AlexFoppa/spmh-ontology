# SPMH — Serapis Personal Mental Health Ontology

Trace-based OWL ontology for organizing depression-related social media evidence with provenance, aligned with DSM-5-TR diagnostic criteria.

## Files

| File | Description |
|------|-------------|
| `SPMH-public.owl` | **Canonical public release** (RDF/XML) — QASAR upload and OOPS! paste |
| `SPMH-public.ttl` | Turtle export of the same ontology (generated by build script) |

## Version

- **1.0.4** — A-box aligned with Tables 17/18; HURON labels; OOPS-clean T-box; validated on QASAR and OOPS! via `SPMH-public.owl`.
- **1.0.0** — prior public release (regressed TBox; superseded).

## Rebuild

Requires a local copy of the pre-redaction A-box source and OOPS-clean T-box (see `scripts/build_spmh_release.py`). Outputs `SPMH-public.owl` and `SPMH-public.ttl`.


If you use this ontology, please cite the SPMH article by Foppa et al. (*A Trace-Based Ontology for Depression Diagnosis from Social Media Data*) and reference this repository. The manuscript is under review; do not cite a specific journal until publication is confirmed.

## Privacy note

The public A-box uses demonstration instances from a single social-media account. Sensitive literals were replaced following the redaction technique described in the paper before release.
